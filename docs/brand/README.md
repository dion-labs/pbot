# pbot brand assets

The pbot identity is an original pocket utility robot: clever, slightly mischievous, and dependable. Its visual cues—an abstract card, a cable, checkpoint lights, and a lowercase `p` antenna—reference local automation without using game artwork or franchise trade dress.

## Files

- `pbot-mascot.png`: transparent full-character master, 1254 × 1254.
- `pbot-icon-master.png`: transparent head-and-antenna icon master, 1254 × 1254.
- `pbot-social-preview.png`: 2:1 repository and README hero, 1280 × 640.
- `public/icons/pbot-512.png` and `public/icons/pbot-192.png`: dashboard icon exports.
- `public/favicon.png`: compact 32 × 32 dashboard favicon.

## Palette

| Role | Color |
| --- | --- |
| Charcoal | `#182026` |
| Warm ivory | `#F3F1EB` |
| Signal red | `#E04B3F` |
| Status green | `#31836B` |
| Checkpoint yellow | `#EABF45` |

Keep clear space around the mascot, preserve its proportions, and pair it with the lowercase `pbot` wordmark or the full name `pbot — Pocket Bot`. Do not combine it with Pokémon artwork, marks, characters, or Poké Ball-like motifs.

The raster masters were generated for Dion Labs with OpenAI image generation and selected after a privacy and trademark review. The social preview uses a sanitized fictional dashboard and contains no account, device, or runtime data.
